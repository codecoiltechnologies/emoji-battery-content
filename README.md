# Emoji Battery Bar - content pack

Remote content for the Emoji Battery Bar Android app. The app downloads `catalog.json` and lazily fetches only the assets a user previews or applies, so the APK stays small.

Served via jsDelivr: `https://cdn.jsdelivr.net/gh/codecoiltechnologies/emoji-battery-content@main/`

See LICENSES.md for third-party attributions. Rebuild with `tools/build_content.py` in the app repo.
